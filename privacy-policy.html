Privacy Policy – Clip Maker

Effective date: October 27, 2026 · Home · Terms of Service

Clip Maker is a personal desktop application for Windows. It is used by its developer only, to edit their own video clips on their own computer and send them as drafts to their own TikTok account. It is not sold, distributed or offered to the public.

1. Data we access

When the user connects a TikTok account, Clip Maker uses TikTok Login Kit and receives, with the user's permission:

  • an access token and a refresh token;
  • the account's open ID and display name (scope user.info.basic);
  • permission to upload videos to the user's TikTok drafts / inbox (scope video.upload).

2. How the data is used

  • The tokens are used only to send the video files that the user explicitly chooses, by clicking "Send as TikTok draft", to the user's own TikTok inbox through the TikTok Content Posting API.
  • The display name is only shown in the app, to confirm which account is connected.
  • Clip Maker never posts publicly on its own: the user reviews and publishes each draft in the TikTok app.

3. Storage and security

  • All data stays on the user's computer. Tokens and the app secret are encrypted with Windows DPAPI (readable only by the user's Windows account on that computer).
  • Clip Maker has no server, no user database, no analytics, no advertising and no tracking.
  • No data is sold, shared with or transferred to any third party. Data is only sent to TikTok, through TikTok's official API, when the user asks for it.

4. Deleting data

  • Clicking "Disconnect" in Clip Maker revokes the TikTok token and deletes it from the computer.
  • The user can also delete the local settings file and remove the app's access in the TikTok app settings at any time.

5. Children

Clip Maker is not intended for children and is used by its adult developer only.

6. Changes

This policy may be updated if the app changes. The effective date above will be updated.
