# clipmaker-perso

Pages publiques de l'application TikTok de **Zinqo** (appelé « Clip Maker » avant la 2.3.0), servies par GitHub Pages : https://dxtr-codex.github.io/clipmaker-perso/

| Fichier | Rôle |
|---|---|
| `index.html` | Page d'accueil de l'application TikTok |
| `privacy-policy.html` | Politique de confidentialité |
| `terms-of-service.html` | Conditions d'utilisation |
| `tiktok….txt` | Fichier de vérification du domaine pour TikTok |

**Ne pas supprimer ni renommer ce dépôt** : l'application TikTok enregistrée pointe vers ces adresses. Les pages gardent l'ancien nom « Clip Maker », celui de l'application chez TikTok.

Le logiciel et ses versions sont sur [DXTR-Codex/zinqo](https://github.com/DXTR-Codex/zinqo) ([site](https://dxtr-codex.github.io/zinqo/)).
